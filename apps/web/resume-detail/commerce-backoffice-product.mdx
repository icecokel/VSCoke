## 기본 정보

- 회사: 주식회사 코드크레용
- 재직 기간: 2023.05 - 2025.07
- 직무: 프론트엔드 개발

고객용 커머스와 판매자·운영자 백오피스를 맡았습니다. 고객의 구매 이후 상태와 운영자가 처리하는 주문·클레임을 연결하고, 앱·백엔드 담당자와 역할을 나눴습니다.

## 고객과 운영자에게 다른 화면 전략 적용

고객 서비스는 모바일 사용 흐름과 개발 여력을 고려해 앱처럼 사용하는 화면을 중심으로 만들고 데스크톱에서도 같은 구조를 재사용했습니다. 반면 판매자·운영자는 주문 목록과 관리 정보를 넓게 확인해야 하므로 데스크톱 중심의 백오피스로 구성했습니다. 두 사용자의 업무 차이를 화면과 개발 범위에 반영한 선택입니다.

고객 화면은 한국어·일본어·영어·중국어 번체를 지원했습니다. 국내·해외 카드와 PayPal 결제 선택, SDK 요청 데이터, 국가별 주소·배송 정보를 연결했습니다. 담당 범위는 결제 프론트엔드와 주문 상태 처리이며 서버 승인·환불 트랜잭션 전체를 소유한 것은 아닙니다.

## 구매 이후에도 이어지는 주문 규칙

결제 이후 선물 수령·취소, 구매 확정, 반품·교환·환불과 리뷰로 이어지는 흐름을 개발했습니다. 부분 반품에서는 대상과 금액을 표시하고, 구매 확정 여부·동일 상품·반품 상태에 따라 리뷰 작성 조건을 적용했습니다. 목록을 오가며 다시 찾는 부담을 줄이도록 무한 스크롤과 복귀 시 목록·스크롤 위치 복원을 다뤘습니다.

라이브 참여 위젯은 5초 간격 조회로 상태를 갱신하고 참여 효과를 표시했습니다. 기본 위젯은 기획 요구사항에서 출발했으며 AWS Polly 음성 안내는 직접 제안해 추가했습니다. 참여율·매출 개선 수치를 측정한 사례는 아닙니다.

## 담당자 변경에 맞춘 백오피스 일괄 전환

기존 Flutter Web 담당자가 앱 개발로 이동한 뒤, 웹 운영 기능을 이어가기 위해 판매자·운영자 백오피스를 Next.js로 일괄 전환했습니다. 이 전환의 프론트엔드를 단독 담당하고 백엔드와 협업했습니다.

판매자 승인, 배너·검색 키워드 관리와 상품·주문·클레임 확인, Excel 작업을 지원했습니다. 판매자·운영자가 담당 업무를 화면에서 처리할 수 있도록 이관·개발했으며 운영 비용 변화는 별도로 측정하지 않았습니다.
