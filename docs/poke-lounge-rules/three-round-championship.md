# Poke Lounge 3라운드 챔피언십 규칙

확인 기준일: 2026-08-18

상위 문서: [Poke Lounge 게임 규칙 인덱스](./index.md)

## 1. 라운드의 의미

챔피언십은 게임 라운드를 정확히 세 번 진행한다. 여기서 게임 라운드는 단일 매치가 아니라
다음 세 단계를 합친 단위다.

```text
준비 5분
→ 2~6인 싱글 엘리미네이션 토너먼트
→ 남은 체력 비율 점수 반영
```

토너먼트 안의 1회전·준결승·결승은 **토너먼트 단계**다. 이것을 1·2·3게임 라운드와 혼동하지
않는다.

## 2. 전체 순서

```text
1라운드 준비 5분
→ 1라운드 토너먼트
→ 1라운드 남은 체력 비율 점수 반영
→ 2라운드 준비 5분
→ 2라운드 토너먼트
→ 2라운드 남은 체력 비율 점수 반영
→ 3라운드 준비 5분
→ 3라운드 토너먼트
→ 3라운드 남은 체력 비율 점수 반영
→ 누적 점수 최종 순위
→ 최종 1위 우승
```

1·2라운드가 끝났다는 이유로 우승자를 조기 확정하지 않는다. 세 라운드를 모두 마친 뒤에만
최종 순위와 우승을 확정한다.

## 3. 라운드 준비

- 1라운드를 포함해 각 라운드 준비 시간은 5분, 즉 `300,000ms`다.
- 준비 중에는 월드를 탐색하고 포켓몬을 포획·성장·회복하며 파티를 편성할 수 있다.
- 준비 종료 시점까지 서버에 반영된 최신 파티를 해당 라운드의 frozen party로 사용한다.
- 파티는 1~6마리이며 선두 포켓몬은 전투할 수 있는 상태여야 한다.
- 종, 레벨, physical slot, 선두, IV, 기술, HP, 상태와 남은 PP를 그대로 동결한다.
- 레벨 보정, 임의 포켓몬 교체와 고정 파티 fallback을 사용하지 않는다.
- 준비 마감 시 유효한 파티가 없는 참가자가 있으면 임의 파티로 경기를 시작하지 않는다.

## 4. 토너먼트 대진

- 참가 인원은 2~6명이다.
- 각 게임 라운드는 싱글 엘리미네이션으로 진행한다.
- seed는 참가 순서와 player ID로 안정적으로 결정한다.
- 참가 인원이 bracket 크기와 맞지 않으면 부전승을 만든다.
- 여러 매치를 동시에 진행하지 않고 서버가 한 매치씩 순서대로 활성화한다.
- 매치 승자는 다음 토너먼트 단계로 진출하고 패자는 해당 게임 라운드에서 탈락한다.
- 마지막 매치 승자가 해당 게임 라운드 토너먼트 1위가 된다.

한 토너먼트 안의 모든 매치는 같은 frozen party에서 시작한다. 앞선 매치에서 발생한 HP 피해,
PP 소비, 상태와 선두 변경은 다음 매치나 월드 파티에 누적하지 않는다.

## 5. 라운드 체력 점수

라운드 점수는 각 사용자가 해당 게임 라운드에서 마지막으로 진행한 매치의 terminal party
snapshot을 기준으로 계산한다. 그 파티에 남은 체력 비율을 모두 더한다.

```text
포켓몬 점수 = 현재 HP ÷ 최대 HP × 100
라운드 점수 = Σ(파티에 포함된 모든 포켓몬 점수)
```

예를 들어 세 마리의 남은 체력이 각각 `100%`, `50%`, `0%`라면 라운드 점수는 150점이다.

- 전투불능 포켓몬은 0점이다.
- 체력이 가득 찬 포켓몬은 한 마리당 100점이다.
- 6마리 파티의 라운드 최대 점수는 600점이다.
- 세 라운드 최종 누적 최대 점수는 1,800점이다.
- 파티가 1~5마리면 실제 파티원만 합산한다.
- 토너먼트 최종 순위에 따른 고정 배점을 사용하지 않는다.
- 매치 terminal의 승자 100점·패자 50점도 챔피언십 점수에 더하지 않는다.

## 6. 누적 점수와 최종 우승

1. 각 라운드의 체력 점수를 기존 누적 점수에 정확히 한 번 더한다.
2. 1·2라운드가 끝나면 현재 누적 순위를 표시하고 다음 5분 준비로 이동한다.
3. 3라운드가 끝나면 누적 점수 내림차순으로 최종 순위를 만든다.
4. 최종 순위 1위가 우승한다.

누적 점수가 같을 때 공동 1위를 허용할지, 별도의 동점 처리로 한 명을 뽑을지는 추가 결정이
필요하다.

## 7. 매치 종료

경쟁 매치는 다음 사유로 끝난다.

| 사유      | 규칙                                                                     |
| --------- | ------------------------------------------------------------------------ |
| `faint`   | 한쪽 파티 전체가 전투불능이 되면 상대가 승리한다.                        |
| `timeout` | 한쪽의 첫 행동 제출 후 상대가 60초 안에 행동하지 않으면 제출자가 이긴다. |
| `forfeit` | 참가자가 나가거나 경기 지속 조건을 잃으면 상대가 이긴다.                 |

종료 사유가 달라도 토너먼트에서는 승자와 패자를 확정해 bracket을 전진시킨다. 라운드 점수는
각 사용자의 라운드 종료 시 남은 체력 비율로 계산한다.

## 8. 저장과 중복 방지

- 매치 terminal, bracket 전진, HP snapshot, 라운드 점수와 다음 상태를 서버가 확정한다.
- 클라이언트가 승자, 점수나 최종 우승자를 직접 제출하지 않는다.
- 같은 매치 결과와 같은 라운드 점수를 새로고침·재접속 때문에 두 번 반영하지 않는다.
- UI, 서버 snapshot과 DB의 누적 점수·최종 순위가 같아야 한다.
