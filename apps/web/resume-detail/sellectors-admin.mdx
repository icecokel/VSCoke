## 기본 정보

- 회사: 주식회사 코드크레용
- 재직 기간: 2023.05 - 2025.07
- 담당: 백오피스 전환의 프론트엔드 단독 개발

## 담당자 변경 후에도 이어가야 했던 운영 기능

기존 Flutter Web 담당자가 앱 개발로 이동하면서 판매자·운영자 기능을 웹에서 이어갈 필요가 생겼습니다. Next.js로 백오피스를 일괄 전환하고 이후 기능 개발을 맡았습니다. 프론트엔드는 단독 담당했으며 API와 업무 규칙은 백엔드·기획 담당자와 협업했습니다.

고객용 서비스는 모바일 중심으로 구성했지만 백오피스는 주문 목록과 관리 정보를 넓게 보는 데스크톱 업무에 맞췄습니다. 고객과 운영자에게 같은 화면 전략을 적용하지 않고 실제 사용 흐름에 따라 나눴습니다.

## 승인부터 주문·클레임까지 운영 화면 연결

판매자 승인, 상품·배너·검색 키워드 관리와 주문·클레임 확인, Excel 작업을 지원했습니다. 목록 조회에서 상세 확인과 처리로 이어지는 흐름을 만들고, 입력 폼과 API 조회 상태는 공통으로 사용하는 라이브러리와 패턴에 맞췄습니다.

전환과 운영 기능 개발이 확인된 결과이며 운영 시간 절감, 응답 속도 향상이나 개발자 의존도 감소를 별도로 측정한 수치는 없습니다. 고객 주문과 이어지는 전체 담당 범위는 커머스·백오피스 통합 상세에 함께 기록했습니다.

## 기술

Next.js, React, TypeScript, MUI, Jotai, SWR, React Hook Form
