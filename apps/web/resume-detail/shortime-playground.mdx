## 기본 정보

- 회사: 주식회사 코드크레용
- 재직 기간: 2023.05 - 2025.07
- 직무: 프론트엔드 개발

모바일 앱 안에서 운세·이벤트·웹게임·설문을 제공하는 Playground를 제안하고, 채택 후 프론트엔드 프로젝트 구성을 주도했습니다.

## 아이디어를 동작하는 시제품으로 설명

앱에 참여형 콘텐츠를 더할 방법을 조사하고 Playground 프로토타입을 만들어 시연했습니다. 제안이 채택된 뒤 기존 운세·이벤트를 먼저 옮기고 선물하기·럭키드로우·설문 등으로 범위를 넓혔습니다. 화면 제작뿐 아니라 앱·백엔드 담당자와 연결할 브리지와 API 계약을 함께 조율했습니다.

Phaser로 FlyingPop과 OpenSesame을 개발했습니다. FlyingPop의 피드백을 바탕으로 팀이 OpenSesame을 선택했고, 기존 보너스를 게임 참여 비용으로 연결했습니다. 프론트엔드 개발과 앱·백엔드 연동을 맡았습니다. 당시 DB에서 확인한 수치를 본인이 회고한 기준으로 주간 고유 이용자는 약 2,000~3,000명이었습니다.

## 앱과 웹 사이에서 끊기지 않는 실행 흐름

WebView에서 콘텐츠 진입·종료·보상 처리가 이어지도록 콜백 payload와 딥링크를 연결하고 진행 중 중복 실행, 콜백 대기와 타임아웃을 다뤘습니다. 앱·백엔드 담당자와 나눈 계약에 맞춰 프론트엔드의 실행 상태를 제어했으며 서버 보상 검증이나 부정 이용 방지는 별도 담당 영역입니다.

Safari 계열 오디오 재생 제약과 앱이 백그라운드로 이동할 때의 재생 중단을 처리했습니다. 키보드가 입력란을 가리는 문제는 앱 수정 여력이 부족한 상황에서 하단 여백을 임시로 확보했습니다. 이 대응으로 모든 기기·앱 버전의 WebView 동작을 해결했다고 보지는 않습니다.
