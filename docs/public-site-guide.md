# VSCoke 사이트 안내

## VSCoke와 메인 채팅

VSCoke는 개발자 이상민의 포트폴리오 사이트다. 메인 화면에서는 공개 프로젝트의 목적,
담당 역할, 사용 기술과 사이트 이용 방법을 질문할 수 있다.

## README와 이력서

README(`/readme`)에서 프로필과 경력 요약을 확인할 수 있다. 이력서 질문 화면
(`/resume/question`)에서는 공개 이력과 경력 자료를 바탕으로 질문하고 답변을 받는다.
이력서 미리보기는 `/resume/preview`에서 확인할 수 있다.

## 블로그

블로그는 `/blog`, 블로그 대시보드는 `/blog/dashboard`에서 확인할 수 있다.

## 게임

Game Center(`/game`)에서 게임을 선택할 수 있다. Sky Drop은 `/game/sky-drop`,
Wordle은 `/game/wordle`에 있다. Poke Lounge는 Game Center의 링크로 이동할 수 있다.

## 취미

에스프레소 관련 화면은 `/hobby/espresso`, 레시피 화면은 `/hobby/recipes`에서 확인할 수 있다.

## 언어

한국어, 영어, 일본어를 지원한다. 페이지 주소에는 선택한 언어에 따라 `/ko-KR`, `/en-US`,
`/ja-JP`가 앞에 붙는다.
