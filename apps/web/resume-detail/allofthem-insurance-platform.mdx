## 기본 정보

- 회사: all of them Co., Ltd. · Japan
- 재직 기간: 2021.07 - 2023.04
- 담당: 보험 서비스 프론트엔드, 별도 고객사 관리자 기능의 Spring·SQL 작업

보험 가입 서비스와 고객사 연동 SDK, 관리자 화면을 개발했습니다. 가입 앱, 고객사 거래 관리, 보험 대리점 계약 관리의 업무 범위를 구분해 담당했습니다.

## 고객사별 설정을 하나의 SDK로 연결

고객사마다 보험 가입 기능을 붙여야 하는 요구에 맞춰 CDN으로 배포하는 공통 SDK를 개발했습니다. 고객사별 공통 연동이라는 요구사항을 SDK 설정과 자산 경로에 반영했습니다.

API key·옵션·고객 정보로 실행 조건을 받고 planId에 맞는 자산 URL을 연결해 하나의 SDK를 고객사별로 설정할 수 있게 했습니다. 프론트엔드 연동과 가입 흐름을 맡고 보험 정책·결제 처리는 담당자와 협업했습니다.

## 기다리는 구간을 먼저 줄인 뒤 렌더링 방식 전환

고객 정보 조회와 여러 요청이 가입 화면 진입을 지연시키는 구간에서 먼저 고객 조회 시점을 앞당기고 독립 요청을 병렬 처리했습니다. 이후 추가 초기 렌더링 이점과 전환 비용을 고려해 React 기반 화면을 Next.js SSR로 일괄 전환했습니다.

일본 고객사에서 약 5초 걸리던 화면 진입이 1.2~1.5초 수준이 됐다는 고객사 보고가 있었습니다. 별도로 한국 데스크톱 Lighthouse에서 LCP 1.2초를 확인했습니다. 두 수치는 보고 주체·환경·지표가 달라 같은 실험의 전후 값으로 합치지 않으며, 가입 전환율 증가는 측정하지 않았습니다.

## 여러 단계의 가입과 관리자 업무

보험별 가입 앱에서 여러 단계의 입력을 이어가도록 복원을 지원하되 카드 정보는 복원 대상에서 제외했습니다. 화면 크기에 맞춰 가입 흐름을 조정하고, 단계별 입력과 다음 행동을 연결했습니다.

별도 고객사 거래 관리자에서는 Spring·SQL 작업까지 맡았고, 보험 대리점 계약 관리 백오피스도 개발했습니다. 각 서비스의 담당자와 협업하며 맡은 기능의 화면·API·데이터 조회를 연결했습니다.

## 기술
