# PostgreSQL / ClickHouse 조회 성능 비교

## 비교 목적

동일한 데이터와 조회 조건에서 PostgreSQL과 ClickHouse의 처리 시간을 비교하고, 조회 유형과 데이터 규모에 따라 성능 우위가 바뀌는 구간을 확인한다.

## 비교 방법

본 비교는 운영 환경의 실제 트래픽을 측정한 것이 아니라, 로컬 환경에 PostgreSQL과 ClickHouse를 설치하고 동일한 데이터와 조회 조건을 구성한 테스트베드에서 진행했다.

1. PostgreSQL과 ClickHouse에 같은 범위의 원본 데이터를 사용한다.
2. 조건 조회, 그룹 집계, 연결 집계를 각각 1건부터 100만 건까지 실행한다.
3. 사전 실행 결과는 제외하고, 각 조건을 데이터베이스별로 20회 측정한다.
4. 20회 실행 시간의 중앙값을 대표값으로 사용한다.
5. 반복 측정의 차이가 명확한 경우에만 빠른 쪽을 판정하고, 차이를 확정하기 어려운 경우에는 판단을 보류한다.
6. 두 데이터베이스가 같은 계산 결과를 반환했는지 확인한다.

## 비교 조건

| 항목        | 내용                                                                 |
| ----------- | -------------------------------------------------------------------- |
| 데이터 규모 | 1,000,000건                                                          |
| 비교 범위   | 1건, 10건, 100건, 1천 건, 1만 건, 3만 건, 10만 건, 30만 건, 100만 건 |
| 조회 유형   | 조건 조회, 그룹 집계, 연결 집계                                      |
| 반복 횟수   | 각 조건·데이터베이스별 20회                                          |
| 대표값      | 20회 실행 시간의 중앙값                                              |
| 실행 방식   | 조회를 한 번에 하나씩 실행                                           |
| 판정 기준   | 실행 시간이 작을수록 빠름                                            |

`비교 범위`는 반환된 행 수가 아니라 계산 대상으로 사용한 원본 데이터의 범위다. 세 조회 모두 요약 결과 1건을 반환했다.

## 결과 요약

| 조회 유형 | PostgreSQL이 빠른 범위 | 판단 보류 | ClickHouse가 빠른 범위 |     전환 후보 |
| --------- | ---------------------: | --------: | ---------------------: | ------------: |
| 조건 조회 |           1건–100만 건 |         - |                      - | 확인되지 않음 |
| 그룹 집계 |             1건–1만 건 |    3만 건 |          10만–100만 건 |   1만–10만 건 |
| 연결 집계 |              1건–100건 |         - |           1천–100만 건 |    100–1천 건 |

## 비교 결과

- 조건 조회에서는 100만 건까지 PostgreSQL이 빨랐다.
- 그룹 집계의 전환 후보는 1만–10만 건이다. 3만 건은 판단을 보류했다.
- 연결 집계의 전환 후보는 100–1천 건이다.
- 세 조회의 전환 구간이 서로 달라 하나의 공통 기준점은 확인되지 않았다.

이 결과는 위의 데이터, 조회 유형, 실행 조건에 한정된다.
