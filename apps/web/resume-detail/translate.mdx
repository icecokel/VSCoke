## 기본 정보

- 회사: 주식회사 코드크레용
- 재직 기간: 2023.05 - 2025.07
- 직무: 프론트엔드 개발

운영자가 개발자 도움 없이 반복 작업을 처리할 수 있도록 자막 번역·검색 도구를 개발했습니다. 고객용 커머스, 판매자·운영자 화면과 WebView 제품을 함께 맡았습니다.

## 개발자용 번역 도구를 운영자의 작업 화면으로 전환

에피소드별 자막을 여러 언어로 번역해야 했지만 초기 CLI는 비개발자인 운영자가 직접 쓰기 어려웠습니다. 여러 파일을 올리고 결과를 확인할 수 있는 웹 도구로 바꾼 뒤 숏타임 백오피스에 편입했습니다. 기본 대상은 독일어·스페인어·태국어·인도네시아어·힌디어·포르투갈어·중국어 간체·번체의 8개 언어입니다.

VTT·SRT 변환과 번역 구간 분할·병렬 처리, 실패 시 더 작은 단위의 재시도를 적용했습니다. 응답 형식을 고정하고 자막 개수, 누락·빈 항목, 시간 정보와 파일 형식을 검사해 운영자가 다시 확인할 지점을 드러냈습니다. 이 검사는 구조와 누락을 확인하는 것이며 모든 언어의 번역 품질을 자동으로 보증하지는 않습니다.

본인 회고 기준 약 3개월 동안 운영자 3~4명이 사용했고, 1명이 에피소드 1편을 처리하는 데 약 3일 걸리던 작업을 하루 6~8편 처리하는 수준으로 바꿨습니다. 동일 조건의 실험 로그로 산출한 생산성 지표는 아닙니다. AI 번역 사용 고지 정책과 함께 운영했으며 고지 배지 UI는 동료가 담당했습니다.

## 세 플랫폼의 검색 결과를 한 번에 확인

운영팀이 같은 키워드로 여러 영상 플랫폼을 반복 검색하던 업무에 맞춰 Bilibili TV·Bilibili·Dailymotion의 후보 영상과 썸네일·링크를 한 화면에 모았습니다. 운영자 3명이 사용했고, 비슷한 키워드 수를 검색할 때 확인 시간이 약 50분에서 10분 이내가 됐다는 운영자 피드백을 받았습니다.

도구의 범위는 확인 후보를 찾는 일입니다. 무단 도용 여부의 자동 판정이나 삭제 조치 성과를 측정한 것은 아닙니다. 검색 처리와 실행 환경의 선택은 별도 검색 도구 상세에 기록했습니다.

## 상품 콘텐츠 초안 생성으로 가설 검토

사용자가 다시 방문할 콘텐츠를 확보하고 백링크 기반 SEO 유입 전략을 검토하기 위해 셀렉터스 상품 블로그 초안을 AI로 생성하는 프로토타입을 제작했습니다. 초안 생성 가능성을 확인한 단계이며 자동 게시 운영이나 리텐션·검색 유입 증가를 성과로 주장하지 않습니다.
