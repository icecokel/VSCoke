## 기본 정보

- 재직 기간: 2023.05 - 2025.07
- 담당: 숏타임 converter·AI 자막 도구와 일부 에피소드 플레이어 테스트

## 운영자가 직접 처리하는 자막 변환·번역

개발자용 CLI로 시작한 자막 번역 도구를 운영자가 직접 사용할 수 있도록 여러 파일을 처리하는 웹 화면으로 옮기고 숏타임 백오피스에 편입했습니다. VTT·SRT 변환, 8개 언어 번역과 결과 확인을 하나의 운영 흐름에서 다뤘습니다.

번역 결과의 개수·누락·빈 항목·시간 정보·형식을 검사하고 분할 처리와 재시도를 적용했습니다. 운영자가 확인한 것은 구조와 오류·누락 중심이며 전체 언어의 번역 품질 검수나 자동 품질 보증을 뜻하지 않습니다.

## 직접 담당한 범위와 협업 경계

직접 개발한 범위는 converter와 AI 자막 도구이며 일부 에피소드 플레이어 테스트를 함께 다뤘습니다. AI 번역 고지 배지 UI는 동료가 담당했습니다.

본인 회고 기준 1명이 에피소드 1편에 약 3일 쓰던 작업을 하루 6~8편 처리하는 수준으로 바꿨습니다. 같은 조건의 실험 로그를 비교한 지표는 아니며 운영 과정과 수치의 맥락은 AI 활용·콘텐츠 운영 도구 상세에 기록했습니다.
