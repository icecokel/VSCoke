- 담당: 검색 도구와 결과 확인 화면 개발

## 반복 검색을 후보 검토 작업으로 전환

운영자가 같은 키워드를 여러 영상 플랫폼에 반복 입력하고 결과를 확인해야 했습니다. Bilibili TV·Bilibili·Dailymotion의 키워드별 영상 후보를 수집하고 썸네일·링크를 한 화면에 표시해 검토할 대상을 모았습니다.

무단 도용 여부는 운영자가 확인하도록 했습니다. 검색 결과에 노출된 영상을 자동으로 불법 콘텐츠라고 판정하거나 삭제를 실행하는 도구는 아닙니다.

## 브라우저에서 막힌 검색 처리를 서버로 분리

브라우저 직접 크롤링에서 봇 차단을 겪은 구간을 Node.js 기반 처리로 분리하고 Axios·Cheerio로 검색 결과를 읽었습니다. 프론트엔드는 검색 입력과 결과 확인을 담당하게 했습니다. 이 방식이 플랫폼 차단을 항상 우회하거나 검색 결과의 완전성을 보장하지는 않습니다.

운영자 3명이 사용했으며 비슷한 키워드 수 기준으로 약 50분 걸리던 확인 작업이 10분 이내가 됐다는 운영자 피드백을 받았습니다. 별도 계측 실험 결과나 탐지 정확도·삭제 처리율을 의미하는 수치는 아닙니다.

## 기술

TypeScript, Express, Axios, Cheerio, Vercel Serverless Functions
