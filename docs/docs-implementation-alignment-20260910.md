## 재검증

`pnpm test:tooling`은 배포 보존·도구 패키징·명령 및 문서 범위 회귀를 실행한다.
`pnpm check:api-contract`는 생성 계약 일치이며 API E2E의 의미 계약 검사도 함께 실행한다.
DB 통합은 `TEST_DATABASE_URL`이 `_test`로 끝나는 별도 DB에서만 실행한다.

상세 실행 로그는 해당 작업 디렉터리의 `output/docs-runtime-alignment/`에 남긴다.
배포 성공 여부는 이 기록의 로컬 검증 결과가 아니라 해당 커밋의 실제 workflow 상태로 판단한다.
